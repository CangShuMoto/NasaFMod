# Hot Shoe Delete and Gap filling
The hot shoe can be removed via some screws, but it will leave some gaps.
![photo of camera with hot shoe removed credit: richard haw](https://richardhaw.com/wp-content/uploads/2020/05/img_5108.jpg?w=768)

There are a couple ways to approach this:
1. make a new cover plate
2. Fill the gap with something

The top covers are made from sheet brass. In order to make a new one, i would need to make a mould and then press it OR send it off to be made. Then I would need to solder on the front bit.

I could also, in the short term, fill the gap with something 3d printed.
